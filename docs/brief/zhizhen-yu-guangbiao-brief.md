# 马原实践作业：火柴人短剧《指针与光标》制作方案与 Agent 提示词

---

## Part 1: 发给 Coding Agent 的 System Prompt（提示词）

你可以直接复制以下框内内容发送给你的 Coding Agent（如 Cursor / Claude Code / Windsurf 等）：

```text
# Role & Goal
你是一名精通程序化动画开发（推荐技术栈：Remotion / Motion Canvas / HTML5 Canvas + GSAP）与视觉叙事的动画工程师。
请根据以下分镜剧本与时间线，编写可直接运行并渲染为 MP4 视频的火柴人动画代码。

# 核心风格与视效规范
1. 视觉风格：极简黑白线稿火柴人，局部彩色点缀（黑色代表现实主角，红色代表超我“完美怪”，蓝色代表本我“摆烂怪”）。
2. 画面布局（上下分屏）：
   - 上半部分：思维剧场（半透明气泡框或思维虚线框内，红蓝火柴人的肢体对抗与互动）。
   - 下半部分：现实书桌（黑火柴人、笔记本电脑、倒计时时钟、精力血条）。
3. 动态与节奏：
   - 动作夸张、喜剧化（拳击、摔倒、头顶黑烟、震动、光标闪烁）。
   - 杜绝枯燥站桩，通过关键帧插值表现流畅肢体拉扯。
4. 叙事约束：
   - 严格遵循戏剧表演叙事，严禁在正片中插入长篇大论的旁白说教。
   - 所有马原哲学隐喻（矛盾的斗争性与同一性、实践与认识）全部通过剧情动作与象征画面呈现。
5. 技术规格：1080P (1920x1080)，30 FPS，片长约 2.5 ~ 3 分钟。
```

## Part 2: 3分钟分镜与动作执行剧本（《指针与光标》）

### 一、 角色与视觉设定

| 角色/元素 | 视觉特征 | 象征意义 | 主要动作 |
| :--- | :--- | :--- | :--- |
| **黑小人（主角）** | 纯黑单线条火柴人，坐在书桌前 | 现实中的行动者/统一体 | 抓头、打字、退格清空、瘫倒、猛敲键盘 |
| **红小人（完美怪）** | 红色线条，戴一副小圆眼镜或拿教鞭 | 超我、苛求完美、脱离实践的“想” | 指手画脚、咆哮、举巨大字典砸人、暴打蓝小人 |
| **蓝小人（畏难怪）** | 蓝色线条，手持发光小手机 | 本我、畏难逃避、拖延焦虑 | 刷手机、瘫成一滩液体、抱大腿、撒泼 |
| **现实环境** | 笔记本电脑、数字时钟、精力槽百分比 | 现实压力与时间维度 | 时钟快速跳动（22:00 -> 23:59）、血条狂跌 |

---

### 二、 分幕镜头与动作指令

#### 【第一幕：对峙与同一体】（0:00 – 0:35）
* **0:00 - 0:10**
  * **现实层**：右上角时钟显示 `22:00`。黑小人精神饱满坐在电脑前，头顶精力槽 `100%`。屏幕上打开了 Word，标题《马原实践作业》，光标在首行均匀闪烁。
  * **音效**：平缓的机械钟表走字声（滴答、滴答）。
* **0:10 - 0:35**
  * **脑内层**：黑小人头顶冒出思维气泡。红小人和蓝小人背靠背跳出。
  * **动作**：
    * 黑小人刚要抬手敲字，红小人突然拔出教鞭大喝：“慢着！第一句不够深刻震撼怎么行？必须先通读三本原著！”
    * 蓝小人顺势从裤兜掏出手机躺平：“就是就是，既然任务这么宏大，先刷 10 分钟短视频找灵感嘛～”
    * 红小人怒视蓝小人，一脚将蓝小人的手机踹飞；蓝小人暴起，用枕头砸向红小人。
  * **音效**：动漫挑衅音、飞踢声、抱枕拍打声。

---

#### 【第二幕：内耗空转（想消耗了做）】（0:35 – 1:30）
* **0:35 - 1:00**
  * **现实层**：时钟快速旋转推进到 `23:20`。黑小人的精力槽肉眼可见地从 `100%` 骤降到 `15%`，头顶冒出灰色晕眩蚊香圈，双手悬空发抖。
  * **电脑屏幕**：黑小人艰难敲出：“马克思指出，实践是……” 随后犹豫两秒，陷入狂躁，按住 Backspace 键连续暴扣，字迹全部消失，光标继续孤独闪烁。
  * **音效**：按键疯狂删除声（哒哒哒哒）、心跳加速声（咚、咚、咚）。
* **1:00 - 1:30**
  * **脑内层**：红蓝火柴人的冲突进入白热化高潮。
  * **动作**：
    * 红小人搬出一本比人还高的巨大《词典》砸在蓝小人头上：“这句太俗！重写！立意要高！”
    * 蓝小人化身粘稠的史莱姆死死缠住红小人的脖子：“写不出来！根本做不到！干脆摆烂重修吧！”
    * 两人在脑内剧场缠斗翻滚成一团剧烈旋转的打架黑烟（经典卡通漫威式打架云）。
  * **隐喻**：现实中一行字没推进，但意识内部的两极撕扯彻底抽干了行动能量。
  * **音效**：卡通打斗摔打音、狂风呼啸声、疲惫长叹。

---

#### 【第三幕：危机触发与实践破局】（1:30 – 2:20）
* **1:30 - 1:45**
  * **现实层**：时钟指针跳到 `23:51`！屏幕突发全屏红光闪烁弹窗：
    > **⚠️ 紧急警告：电池电量仅剩 3%！距离提交截止仅剩 8 分钟！**
  * **动作**：黑小人浑身一震，被现实危机猛然拉回。
  * **音效**：刺耳的防空警报声、低电量提示嘟嘟声。
* **1:45 - 2:20**
  * **核心动作（实践介入）**：
    * 黑小人不再纠结脑内的争吵，咬紧牙关，双手化作重影疯狂砸向键盘！
    * 屏幕上没有字斟句酌的华丽辞藻，而是粗暴但直接地跳出大段框架：
      `1. 选题背景：大学生的内耗`
      `2. 核心原因：思虑过多与行动停滞`
      `3. 解决路径：先做起来再迭代`
  * **脑内震荡**：
    * 现实中的键盘敲击如同重磅陨石，一块块带字的石块轰然砸入脑内剧场。
    * 缠斗中的红蓝小人被冲击波当场掀翻，两人摔在地上发懵。
  * **音效**：机关枪般的重击键盘声、地震轰鸣音。

---

#### 【第四幕：矛盾转化，落笔成章】（2:20 – 2:45）
* **2:20 - 2:35**
  * **脑内层**：
    * 红小人扶了扶歪掉的眼镜，爬起来审视掉落的粗糙文字：“这句子虽然粗糙……但核心观点居然立住了？结构改改就能用！”
    * 蓝小人拍拍屁股坐起来：“既然骨架都有了，我负责填第二段的例子，赶紧搞完睡觉！”
    * 两人从死斗状态转入协同：红小人手持红笔迅速修改标点，蓝小人拿起铁锹搬砖填补空缺段落。
  * **音效**：快节奏的轻快滑稽配乐、铅笔沙沙声。
* **2:35 - 2:45**
  * **现实层**：时钟显示 `23:58:30`。文档显示 `100% 完成`。
  * **动作**：黑小人猛按回车键，鼠标狠点【确认提交】。
  * **反馈**：屏幕正中央弹出一个清脆的绿色大对勾：**【提交成功】**。
  * 黑小人整个人像脱力一样瘫软倒在靠背椅上，双眼望天，嘴角泛起释怀的傻笑。
  * **音效**：鼠标清脆的“Click”、任务完成提示音（叮——）、长舒一口气（呼……）。

---

#### 【尾声：艺术留白与学术落款】（2:45 – 3:00）
* **画面变化**：
  * 现实场景与脑内剧场同步向中心收缩，屏幕渐隐进入纯黑背景。
  * 拒绝任何说教旁白，中央淡入极简演职员名单与教学考评出处标注：
* **字幕文字**：
  ```text
  《指针与光标》
  
  课程作业：马克思主义基本原理实践教学
  指导教师：许老师
  制作成员：[你们小组的名单]
  
  哲学映射：
  · 矛盾的同一性与斗争性
  · 实践与认识的辩证运动过程
  ```
* **音效**：淡出直至寂静。

## Part 3: 组内协作与技术落地建议

1. **若给 Agent 运行代码**：
   * 优先让 Agent 选择 **Remotion**，因为火柴人结构仅需定义 SVG 点位坐标（`head: cx, cy`, `body: x1, y1, x2, y2`），通过 `interpolate` 改变坐标就能极为丝滑地实现出拳、被踢飞、打字手部抖动。
2. **若 Agent 生成代码报错难以调试（备用路线）**：
   * 可将本 Markdown 剧本中的 6 个关键动作截图/静态图，直接在剪映中拼贴为定格动画，配合剧本里的音效点，半天即可成片。
