# 《指针与光标 2.0：拔掉退格键》— 马原实践作业火柴人短片（Remotion）

纯 SVG + React（夜景窗户、台灯、书桌、垃圾桶等背景也全部用 SVG 画），没有用任何外部图片或音频。

- Composition id：**`PointerAndCursor`**
- 1920×1080 · 30fps · **7200 帧（4:00）**
- 布局：
  - 上半「思维剧场」：红＝完美主义（戴眼镜，拿黑色教鞭），蓝＝畏难逃避（缩身、犹豫），黑＝主角化身。
  - 下半「现实」：**第一人称书桌**。屏幕正对观众，键盘上有 `← Backspace` 键，画面里有双手和肩部剪影。
  - 运镜：推拉、硬切和特写（屏幕、退格键、手机、桌角、垃圾桶、抬头看日历、主角脸部插入镜头）。
  - 环境动态：星星、楼宇灯光、窗帘、台灯闪烁、飞蛾、咖啡热气。
- 中文字体：`Noto Sans CJK SC, PingFang SC, Microsoft YaHei, sans-serif`。换机渲染需要装其中任一种中文字体。

## 运行 / 渲染
```bash
npm i
npm run dev                       # Remotion Studio
npx tsc --noEmit                  # 类型检查
npx remotion render src/index.ts PointerAndCursor out/zhizhen-yu-guangbiao-v4.mp4
npx remotion still  src/index.ts PointerAndCursor out/check.png --frame=4330
```
